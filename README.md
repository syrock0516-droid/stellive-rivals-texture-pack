# Stellive Rivals Texture Pack

로컬 PC 경로를 제거하고 GitHub Raw URL로 배포할 수 있게 정리한 버전입니다.

- `rivals-texture-pack.json`: 바로 사용할 최종 JSON
- `assets/`: 공개 Raw URL로 제공되는 이미지와 폰트 21개
- `missing-assets.json`: 원본 ZIP에 없어서 비활성화한 에셋 14개
- `included-assets.json`: 업로드된 에셋과 규칙 매핑

최종 JSON 주소:

```text
https://raw.githubusercontent.com/syrock0516-droid/stellive-rivals-texture-pack/main/rivals-texture-pack.json
```
